# Legacy ActivityNet Work

This directory preserves the former ActivityNet temporal-retrieval experiment,
paper artifacts, and operational notes.

ActivityNet is not an active dataset or architecture target. These files remain
for provenance and may reference scripts and interfaces that are still present
in the repository during migration.

Do not:

- use ActivityNet profiles as defaults for new CASTLE modules;
- describe ActivityNet metrics as CASTLE evidence;
- extend the ActivityNet evaluation path instead of the Event Manifest path.

Relevant decision: [ADR-0009](../../adr/0009-focus-research-and-active-architecture-on-castle.md).
